A tiny program that writes one short, quiet text — the last train of the evening, slowing for empty stations and rocking a few quiet people home through the dark — meant to leave whoever reads it a little more at ease. It never tells the reader to relax; it just refuses to hurry.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
